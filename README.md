# SmartGuard

Android-приложение для защиты от телефонного и SMS-мошенничества с использованием машинного обучения.

## Возможности
- 🤖 ML-классификация фишинговых SMS (CNN+LSTM, TensorFlow Lite)
- 📞 Интерактивный ассистент во время звонка
- 🔒 Полная локальная обработка данных (Offline-first)
- 🎓 Образовательный модуль "SmartGuard Академия"
- 🛡️ Защита от root-устройств и модификаций APK

## Технологии
- Kotlin, Android SDK
- TensorFlow Lite (On-Device ML)
- Room Database, EncryptedSharedPreferences
- Clean Architecture (5-layer)
- Coroutines, Flow
